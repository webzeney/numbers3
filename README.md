# ナンバーズ3 候補選出システム

210通りの組み合わせから検証可能な一様ランダムで候補4数字を選び、
全履歴7080回の検定結果とあわせて公開する静的サイト。

## 構成

```
index.html              サイト本体（依存ライブラリなし・単一ファイル）
generate.py             候補生成と統計計算（標準ライブラリのみ）
data/NUMBERS3_ALL.csv   全履歴（第1回〜最新）
data/latest.json        次回の候補・選出記録・統計
data/archive/index.json 遡及計算した過去の候補と結果
docs/仕様書.md          設計の根拠と却下した案
```

## 使い方

```bash
python3 generate.py     # 履歴を更新して data/*.json を生成
python3 -m http.server 8765   # ローカル確認（fetchを使うのでfile://では動かない）
```

## 設計の要点

- **選出は一様ランダム**。0〜9から4つを選ぶ210通りから等確率で1組を選ぶ
- **種は「回号 + 直近確定番号」のSHA-256**。前回結果が出るまで計算できず、出た後は誰でも再現できる
- **伝統手法（ひっぱり・裏数字など）は採点に使わない**。全履歴の検定で基準値と差がないため、選出後のタグ表示のみ
- **データが古ければ生成を止める**。前回値の流用はしない

詳細は `docs/仕様書.md` を参照。
