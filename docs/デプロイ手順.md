# デプロイ手順（ロリポップ スタンダード + GitHub Actions）

毎日0時にGitHub Actionsが候補を生成し、rsyncでロリポップへ配信する構成。
ロリポップ側のPython環境に依存しないので、バージョン問題で詰まることがない。

## 全体像

```
0:00 JST  GitHub Actions 起動
          ↓ loto-life / mk-mode から結果を取得（前夜19:50頃に公開済み）
          ↓ 前回の結果を保存版ページに記入、3AIを採点
          ↓ 次回向けの候補を生成、3AIに問い合わせ
          ↓ data/ をリポジトリにコミット（履歴として残る）
          ↓ rsync で ロリポップへ配信
          公開
```

## 手順1: リポジトリにファイルを置く

このパッケージの中身をリポジトリのルートに配置する（`index.html` がルートに来る形）。

```
index.html
generate.py
ai_picks.py
data/
docs/
tools/
.github/workflows/daily.yml
```

サイトがリポジトリのサブフォルダにある場合は、`daily.yml` の各stepに
`working-directory: サブフォルダ名` を足し、rsyncの `./` をそのフォルダに変える。

## 手順2: APIキーをGitHub Secretsに登録

リポジトリの **Settings → Secrets and variables → Actions → New repository secret**

| 名前 | 値 |
|---|---|
| `OPENAI_API_KEY` | `sk-proj-...` |
| `ANTHROPIC_API_KEY` | `sk-ant-...` |
| `GEMINI_API_KEY` | `AQ...` |

3つとも任意。未登録ならそのAIの欄が「未設定」と表示されるだけで、生成は止まらない。

## 手順3: ロリポップのSSH設定

1. ユーザー専用ページ → **サーバーの管理・設定 → SSH**
2. 「SSHを有効にする」→ 表示される **サーバー / ユーザー名 / ポート** を控える
3. 秘密鍵をダウンロードする

## 手順4: 接続情報をGitHub Secretsに登録

| 名前 | 値 | 例 |
|---|---|---|
| `LOLIPOP_SSH_HOST` | SSHのサーバー名 | `ssh○○.lolipop.jp` |
| `LOLIPOP_SSH_USER` | SSHのアカウント名 | `○○.jp-○○` |
| `LOLIPOP_SSH_PORT` | ポート番号 | `2222` |
| `LOLIPOP_SSH_KEY` | ダウンロードした秘密鍵の**中身をそのまま**貼る | `-----BEGIN ...` から `-----END ...` まで |
| `LOLIPOP_DEST` | 公開ディレクトリのパス | `/home/users/○/○○/web/numbers/` |

`LOLIPOP_DEST` は、ロリポップ!FTPで対象フォルダを開いたときのパス。
末尾のスラッシュを忘れないこと（rsyncの動作が変わる）。

## 手順5: 動作確認

リポジトリの **Actions → 「毎日の候補生成とデプロイ」→ Run workflow** で手動実行する。

- 緑（成功）で `候補を生成した` → 配信まで完了
- 緑で `すでに生成済み` → 正常（その回はもう作ってある）
- 黄色の警告で `データが未更新` → 正常（結果の公開待ち）
- 赤 → ログを確認

## rsyncの除外設定

配信されないもの: `.git*` / `__pycache__` / `tools/`（テスト用）/ `base.csv` / `data/sources/`（取得元の生データ）

`--delete` を付けているので、リポジトリから消したファイルはサーバー上からも消える。
**公開ディレクトリに他のサイトのファイルがある場合は `--delete` を外すこと。**

---

## 代替案: ロリポップのcronで直接動かす

GitHub Actionsを使わない場合。スタンダードならcronが使える。

```
0 0 * * * cd /home/users/○/○○/web/numbers && /usr/local/bin/python3.x generate.py --if-new >> generate.log 2>&1
```

注意点:

- **python3のパスを先にSSHで確認すること**。ロリポップはSSHとcronで違うバージョンが使われる報告が多い
  ```
  ssh接続後: which -a python3 && python3 -V
  ```
- APIキーはcronのコマンド内で `export` するか、`.env` ファイルをサイト内に置く（`.env` は自動で読まれる）
- `.env` を置く場合は**公開ディレクトリから読めないよう `.htaccess` で遮断すること**
