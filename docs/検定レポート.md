## この結果が設計に与える意味

1. **原典ルールに予測力はない**（ひっぱり27.26% vs 基準27.10%、裏数字27.36%、桁別ひっぱり10.0%）。伝統手法を「低重みの説明タグ」に留めるという討論の判断は、データによって裏づけられた
2. **抽選機に経年の偏りもない**（5年ブロックごとの検定すべて偏りなし）。摩耗・更新による分布変化は検出できない
3. **曜日バイアスも季節性もない**。高湿度期(6-9月)と低湿度期(12-3月)の分布は同質（χ²=8.24 < 16.92）。**湿度仮説は、少なくとも月レベルの代理指標では支持されない**
4. **「6」は歴史的にむしろ出にくい側**。全期間で8位、十の位と一の位では**最下位**。それをサイトは84%の回で候補に選んでいた
5. **和の1次自己相関 r=+0.0106**（有意水準0.0238未満）。回と回は独立で、時系列モデルの入る隙はない

つまり、**予測力を追う方向に伸びしろはゼロ**であることが7080回分で確定した。
設計の目的関数は「多様性のあるもっともらしさ」と「検証可能性」に置くべきである。

# ミニ（下2桁）に限定した項目別検定

2026-10-14 追加。上の14検定は**ナンバーズ3全体（3桁）**を対象にしていた。
ミニ専用サイトである以上、**下2桁に限定した検定**が必要という指摘を受けて実施した。

**データ**: 第1回〜第7091回（7,091回・前回との比較なので7,090組）

## 検定方法

原典の鉄則はいずれも「前回の当選番号から、次回出そうな数字の集合 S を作る」という形に書き直せる。
集合のサイズは回ごとに変わる（例: ひっぱりは前回がダブルなら2個、トリプルなら1個）ため、
**単純に実測率と固定の基準値を比べるのは誤り**である。
回ごとに期待値 |S|/10 と分散を積み上げ、合計と比較した。

- **各位**: 下2桁の十の位・一の位それぞれが S に入っていたか（試行数 = 7,090 × 2）
- **両方**: 下2桁の両方が S に入っていたか ＝ **ミニが当たる条件そのもの**

## 結論

**10項目すべてで有意差なし。ミニに限定しても、有効な鉄則は一つも存在しない。**
最大でも裏数字の各位 z=+1.22（偶然でも約22%の確率で出る大きさ）。

なお、鉄則が「当たっているように見える」のは、**集合の大きさから決まる当然の的中分**を
差し引いていないためである。たとえばひっぱりは前回の番号に平均2.71個の数字が含まれるので、
何も考えずに数えても27.1%は当てはまる。この基準と比べて初めて効果の有無が分かる。

実装は `generate.py` の `mini_rule_tests()`。毎回の生成時に全履歴から計算し直し、
`data/latest.json` の `stats.mini_rules` に出力してサイトの「02 攻略本の鉄則は、本当に効くのか」に表示している。
