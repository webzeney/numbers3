## この結果が設計に与える意味

1. **原典ルールに予測力はない**（ひっぱり27.26% vs 基準27.10%、裏数字27.36%、桁別ひっぱり10.0%）。伝統手法を「低重みの説明タグ」に留めるという討論の判断は、データによって裏づけられた
2. **抽選機に経年の偏りもない**（5年ブロックごとの検定すべて偏りなし）。摩耗・更新による分布変化は検出できない
3. **曜日バイアスも季節性もない**。高湿度期(6-9月)と低湿度期(12-3月)の分布は同質（χ²=8.24 < 16.92）。**湿度仮説は、少なくとも月レベルの代理指標では支持されない**
4. **「6」は歴史的にむしろ出にくい側**。全期間で8位、十の位と一の位では**最下位**。それをサイトは84%の回で候補に選んでいた
5. **和の1次自己相関 r=+0.0106**（有意水準0.0238未満）。回と回は独立で、時系列モデルの入る隙はない

つまり、**予測力を追う方向に伸びしろはゼロ**であることが7080回分で確定した。
設計の目的関数は「多様性のあるもっともらしさ」と「検証可能性」に置くべきである。
