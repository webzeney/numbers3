## 13. 環境物理要因（6周目の新議題）

### 確認された事実

- 宝くじ公式サイトの記載により、ナンバーズの抽せんは**電動式風車型抽せん機**で行われる。**ボール式ではない**
- したがってロト系で語られる「湿度がボールを帯電させる」という経路は**この抽選方式には当てはまらない**
- 未確認（ファンサイト由来・要検証）: 桁ごとに別の抽せん機を使い、数字配列も桁ごとに異なるとの記述。事実なら桁位置別分析（M / C18 / E）に物理的正当化が与えられる

### 仮説として挙がった物理経路

| 記号 | 経路 | 検証可能性 |
|---|---|---|
| C31 | 回転円盤の摩擦・潤滑の温度依存（グリス粘度が季節で変化） | 気象データと突合可能 |
| C32 | 矢の発射機構のばね定数・空気圧が温湿度で変化 | 間接的 |
| C33 | 材料の熱膨張による軸受クリアランス変化 | 間接的 |
| C34 | 静電気（低湿度ほど帯電しやすい。冬場の偏りで間接検証） | 気象データと突合可能 |
| C35 | 経年摩耗で偏りが育つ | 変化点検知で可能 |
| C36 | 抽選機の個体差（7台あるとされる機体のどれを使ったか） | 機体IDが非公開なら不可 |
| G-33 | 電源電圧・周波数ゆらぎがモーター回転数に影響 | 電源ログ入手困難 |

### 統計設計上の必須条件（3者合意）

| 項目 | 内容 |
|---|---|
| サンプル数 | **57回では絶対に不足**。全履歴7000回超が必要（GPT: 桁別なら各桁約7000観測。気象変数をビン分けするなら各ビン最低1000回） |
| 事前登録 | 使用変数・ラグ・桁別/全体・検定式を**検証前にコード化してGitHubに公開**し、公開日以降のデータでのみ検定（Gemini） |
| 多重比較補正 | Benjamini-Hochberg法によるFDR制御を必須化 |
| データ分割 | 年代順に train / validation / holdout |
| ネガティブコントロール | 無相関な乱数出力を同じ検定にかけ、それが有意と出たら**システムを停止** |
| 交絡 | 季節性・曜日・機械更新時期・年末年始の休止を統制 |
| 記録 | ロジックhash・データ取得日・除外条件をJSONに保存 |

**共通認識**: 数字選択式宝くじの還元率はおよそ45%とされる。仮にバイアスを検出しても、**55%の不利を覆すほどの効果量は現実的にありえない**。よって検出したバイアスの用途は「賭けで勝つこと」ではなく「抽選システムの健康診断結果」としての透明性コンテンツ。

**初期実装に含めるもの（Gemini提言）**: 気象庁等の公開データを自動取得して履歴に統合するパイプラインと、データ格納用JSONの器を作るところまで。物理予測に計算リソースを割かず、統計の信頼性担保を優先する。
