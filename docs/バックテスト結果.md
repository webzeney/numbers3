# バックテスト結果: 4戦略の比較

- 対象: 第101回〜第7080回（**6980回分**）。各回、その回より前のデータのみを使って候補4数字を出し、実際の当選番号で採点（時系列リークなし）
- 実装: `engine.py`

## 4つの戦略

| 戦略 | 内容 |
|---|---|
| **current** | 現行サイト風。相関した4要素（ひっぱり・頻度・勢い・連番）の素点を合計し、上位4つを決定論的に取る。※サイトのコードは非公開のため、観測できた点数体系から再構成した近似実装 |
| **improved** | 改良ポイント制。順位点方式＋冷却＋採用率制御を入れ、210組から選ぶ |
| **uniform** | 210組から一様ランダム。回号と直近当選番号のSHA256で決定論的に再現可能 |
| **control** | 完全ランダム（対照群） |

## 読み方

### 予測精度は4戦略すべて同じ

平均カバー桁数は 1.197 / 1.198 / 1.221 / 1.181 で、理論基準1.200と区別できません（標準誤差は約0.010なので、uniformの1.221もノイズの範囲）。**どれを選んでも当たりやすさは変わらない**ことが6980回分で確認されました。

### 現行風ロジックの病理が再現された

| 指標 | current | 実サイトの実測（57回分） |
|---|---|---|
| 連続回のセット重複 | 2.89個 | 2.96個 |
| 同じ数字の最長連続採用 | **60回** | 14回（観測期間が短いため） |
| 採用回数のχ² | 376.4 | — |

再構成した実装が実サイトとほぼ同じ重複度（2.89 vs 2.96）を示したので、**「6」の固着は実装の細部ではなく構造そのものから生じている**ことが裏づけられました。最長60回連続という数字が、この構造の帰結です。

### 改良版で得られた設計上の発見

パラメータ探索（60通り）で分かったのは、**冷却を十分に効かせると、セット距離ペナルティが不要になる**ことです。

- セット距離ペナルティを強くすると、連続回の重複が 0.04個 まで下がる。これは「前回の数字を必ず避ける」という**新たな決定論的な癖**であり、無相関（基準1.60個）から逆方向に外れた別の欠陥
- 冷却1.8＋採用率制御8.0・距離ペナルティなしで、重複1.59個（基準1.60）に着地。**多様性の目標は「0」ではなく「無相関」**

### 最終比較

| | current | improved | uniform |
|---|---|---|---|
| 精度 | 基準どおり | 基準どおり | 基準どおり |
| 連続回の重複 | **2.89（異常）** | 1.59（無相関） | 1.61（無相関） |
| 最長連続採用 | **60回** | 6回 | 12回 |
| 採用率のχ² | **376.4** | 68.4 | 3.4 |
| 説得力（読み物） | スコア表が出せる | スコア表が出せる | 後付けタグのみ |
| 実装・検証の容易さ | 複雑 | 中 | **最小** |

currentは多様性のすべての指標で失格。improvedとuniformは実用上どちらも問題なく、**選択は「スコア表という読み物を残すか」だけの判断**になります。
